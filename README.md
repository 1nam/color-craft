# ColorCraft

A small browser-based color playground built with plain HTML, CSS, and JavaScript.

## Try it

Open `index.html` directly in a browser, or publish the repository with GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository named `colorcraft`.
2. Upload the files in this project to the repository root.
3. On GitHub, open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select your main branch and the `/ (root)` folder.
6. Save. GitHub will provide the public site address.
